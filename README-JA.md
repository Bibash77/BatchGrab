# Batch Grab 0.4.0

[English](README.md) · 無料のChrome拡張機能

ウェブページの画像や文書を選び、名前を確認して保存できます。英語・日本語のUIに対応しています。アカウント、決済、Batch Grabへの利用状況送信はありません。

## インストールと使い方

Chromeウェブストアでの公開はまだ確認されていません。任意のデベロッパーモードのベータ版として、`dist/batch-grab-0.4.0-beta.zip`を展開し、Chromeの`chrome://extensions`でデベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」を選びます。`manifest.json`のあるフォルダーを指定してください。

通常のHTTP(S)ページを開く → Batch Grabを開く → 必要な画像・文書を選択 → 保存 → 結果を確認します。少数のファイルから試し、受付メッセージを待ってください。受付後はポップアップを閉じられますが、Chromeは起動したままにしてください。

「おすすめ」はコンテンツ候補を表示し、「要確認」「サイト素材」「すべて」でも他の候補を確認できます。名前は「詳細・名前」で編集でき、フォルダーやフィルターなどは「設定」にあります。完了は応答の保存完了を示すもので、内容の正しさは保証しません。

## 制限とプライバシー

アクセス制限の回避、自動巡回、自動スクロール、変換、ストリーミング動画の取得には対応しません。分類や名前はページの情報による推定です。ブラウザー終了やOS休止後の復旧は未認証です。

スキャンやダウンロードの情報はChromeの端末内に保存します。プレビューや保存では元のサイトへ通信します。履歴の消去、スキャンの消去、アンインストールが可能ですが、保存済みファイルやChrome自体の記録は別です。CSVには秘密のURLや端末内パスが含まれる可能性があるため、共有前に確認してください。
