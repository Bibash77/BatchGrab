Start with a small task

Chrome Web Store publication is pending. The developer-mode ZIP is an optional beta alternative, not a store-reviewed release.

Download free beta 0.4.0
  1. Unzip the beta into a folder you can keep.
  2. Open chrome://extensions in desktop Chrome. Enable Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Pin Batch Grab from Chrome’s extension menu. Open a normal webpage and click its icon.
  5. Choose English or 日本語 in the popup. Start with 3–5 files you are allowed to download.

Wait for existing jobs before updating; reload the same unpacked folder. Keep Chrome running during downloads.
