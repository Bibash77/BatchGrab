Know what you are trying

Useful within clear limits.

A local Chrome beta for accessible files. Suggestions need review; a saved response still needs checking.

What does Batch Grab do?

It scans the current page for supported resource candidates, shows a visual file list, proposes editable document names and section folders, runs local Chrome downloads and records outcomes. You can export a local CSV of sources and actual saved paths.

Which websites are supported?

It works with links and resources a permitted normal HTTP(S) page exposes. Controlled PDF/CSV/XLSX fixtures and public IRS, NASA and Books to Scrape pages were tested; those are examples, not permanent compatibility promises. Chrome system and Web Store pages cannot be scanned. Pages generating hidden URLs after interactions can be incomplete.

Does it read or rename existing PDFs?

No. Document naming uses webpage labels, not PDF contents or OCR. It does not rename an existing Downloads library, look up DOIs or replace a citation manager such as Zotero.

Why does it need these Chrome permissions?

activeTab and scripting let it read the page you invoke it on. downloads starts transfers and reads actual Chrome outcomes. storage keeps local drafts and jobs. alarms wakes queue reconciliation. Version 0.3.1 requests no persistent all-sites host permission.

Does anything go to an AI or Batch Grab server?

No AI, proxy, account service or Batch Grab telemetry is included in the extension. Previews and downloads contact the original source hosts. Website hosting can create ordinary request logs once deployed; no analytics is enabled in this local site.

Can I close the popup?

After the jobs-saved confirmation, accepted downloads run in the background. Keep Chrome running. Popup closure and a controlled service-worker restart were tested. Browser shutdown, OS suspension and every device/site are not certified.

Does completed guarantee the right document?

No. It means Chrome saved a response. Inspect important files and reconcile the expected set. A server can return a sign-in page or other wrong content. Manual retry is available for failed attempts.

What are the limits?

500 files per batch, 1,000 pending jobs, 10,000 scan results and 60 rendered cards per page. Very large drafts can require rescan. No combined multi-page project, CSV/URL import, ZIP, conversion, protected-content bypass or automatic content validation.

What about image naming and extra resources?

The visual picker remains available. Image suggestions show their evidence and need explicit acceptance. Responsive/lazy alternatives, open shadow roots and accessible same-origin frames are scanned; optional CSS/loaded-image candidates go to Review. Some alternatives are duplicates, decorations or inaccessible.

How do I delete local records?

Clear finished history in outcomes to remove finished job records. Removing the extension clears its extension storage; it does not remove saved files or Chrome’s own Downloads history. Drafts can retain page labels and URLs. Exported CSV files can contain sensitive tokens and local paths—review before sharing.

Is $5 a live price or checkout?

It is a one-time pricing proposal being evaluated. Beta evaluation is free and the full workflow currently has no enforced paid gate. Payment infrastructure is inactive. An interest message is not a payment or order.

How can I ask for help?

Use the beta page to prepare a non-sensitive message. The local preview does not send it. The publisher must configure a real contact email before public launch. Do not send client documents, login details or private URLs.
