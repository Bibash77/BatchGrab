Practical workflow guide

Build a document folder another person can understand

Names, folders and sources belong in the same handoff.

A client should not need your browser history to understand the folder you deliver. A simple structure is often enough: one project root, a small number of meaningful sections, descriptive names, and a source index.

A fictional example

Client research / Finance and Governance / 2025 Annual Report.pdf

This is illustrative data, not a customer result. Use the year and title shown in the real source. Do not add an “official” or “final” label unless you have established it.

Before the handoff

  • Check that the file list matches the agreed scope.
  • Resolve duplicate-looking names without overwriting an existing file.
  • Separate unresolved failures from delivered files.
  • Keep original source URLs and actual local filenames together.
  • Remove private access tokens or local path details before sharing the index externally.

Batch Grab can suggest section folders from page headings, lets you edit names and subfolders, and exports a local source/outcome CSV. It saves under Chrome’s Downloads directory. It does not share files with clients, merge multiple pages into a project or check whether the underlying document is the latest version.

Use a five- or ten-file sample with the person receiving the handoff. Their ability to identify the files matters more than an impressive resource count.
