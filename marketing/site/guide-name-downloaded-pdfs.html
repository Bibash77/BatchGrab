Practical workflow guide

Stop losing context when a file is called download.pdf

A descriptive name starts with the source page, not a guess about the document.

A folder full of download.pdf and numbered copies makes a later handoff difficult. Before saving a large batch, identify where each proposed name comes from.

Use the strongest available label

  1. Check the visible link text. “2025 Annual Report” is usually more useful than a URL such as d001.pdf.
  2. If the link just says “Download PDF,” check its own row or document card for a descriptive title.
  3. Retain a year only if it appears in the source label. The download date is not necessarily the document date.
  4. Preview several names and correct ambiguous titles before starting the whole batch.

Existing free downloaders may already help: Simple Mass Downloader supports a Link text naming mask. That works well when links are descriptive; a generic link can still produce a generic filename.

Keep a source index

Record the source page, original URL, intended name and actual saved path. This preserves context if two documents have similar titles. It is an index, not a guarantee that a file is authentic or current.

Batch Grab suggests names from visible link text and relevant nearby labels. You can edit the names before saving. It does not read inside PDFs, infer authors or rename an existing local document library. Try a small subset on your actual page first.
