Install or update

  1. Unzip the downloaded file into a folder you can keep.
  2. Open chrome://extensions in desktop Chrome and enable Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. If that folder is already installed, use Reload on its extension card. Disable older duplicate copies.
  5. Open a normal HTTP(S) document page, click Batch Grab, and check the header says beta 0.3.1.

Let pending jobs finish before disabling or removing an older installation. A different extension ID or Chrome profile does not automatically inherit local history.

Use a real, supported task

Good first trials have accessible PDF, CSV or XLSX links, weak URL filenames and useful labels on the page. We are particularly interested in independent consultants, researchers and assistants preparing a client folder.

Do not send private source links, client files, credentials or access tokens. The extension does not read PDF contents or bypass restricted pages. Check limits and permissions.
